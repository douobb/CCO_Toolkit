# CCO Toolkit

[繁體中文](README.md)

An unofficial site with calculators and game guides for CyberCode Online players. It is not affiliated with or endorsed by the game's developers.

Built with Next.js, React, TypeScript, and Fumadocs MDX, with static export enabled.

- Game: [CyberCode Online](https://cybercodeonline.com/)
- Game data source: [CCO Found](https://docs.google.com/spreadsheets/d/1wJLuZhZg_Xs1ouyjh6chntY8p3lcgNTuRU3-9JwKxQ4)
