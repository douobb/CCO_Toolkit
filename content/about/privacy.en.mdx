Updated: 2026-10-04

This is the current CCO Toolkit privacy notice. The site currently does not require an account or sign-in.

## Data handled by this site

Current player data includes:

- Shared player inputs: player and skill levels, prices, exchange and cache conversion rates, and equipment or combat values.
- Tool-specific state: inputs, buffs, and working state for individual tools; supported features may also save backpack-planning quantities and loot-box analysis records.

This data is used to prefill inputs, share settings across tools, perform calculations, and preserve working state in the current browser.

## Storage, imports, and exports

Player data is stored in the current browser's `localStorage`, not in a site backend database. The current code does not send this player data to the site backend.

The settings page creates export files in the browser and downloads them. Import files are read and validated in the browser before being written to `localStorage`; the site does not receive these files. Users are responsible for keeping their import and export files safe.

## Submission messages

Player data in the browser and submission messages are separate data flows; the localStorage description above does not apply to private messages. You can send text or attachments by messaging douobb on the official CyberCode Online Discord, or message the site owner in game. In game does not support attachments, so send files through Discord. This site has no contribution form or on-site receiving endpoint. Discord and the game platform handle those messages under their own policies.

The site owner processes only the name, message, and attachments you provide to review submissions, contact you, and keep records of adopted contributions. Sending a private message does not itself grant permission to use or publish a submission. The applicable license will be confirmed separately before adoption, and consent to the displayed name and details will be obtained separately before publishing attribution or an adoption record.

To request a correction, hiding, or withdrawal, contact the site owner through the same channels. The platforms control how they handle and retain their messages and attachments; this site cannot control platform-side data and does not promise a fixed retention period or deletion of platform-side copies.

## Clearing data and data loss

- Clearing this site's browser data removes saved player inputs and tool state; each tool and the settings page also provide reset controls with feature-specific scope.
- In private browsing, `localStorage` usually lasts only for that private session and may disappear when it closes.
- A new device or domain has separate browser storage and does not sync automatically; use an export file that you keep yourself to move data.

## Cookies, analytics, and advertising

The current site code does not set or read cookies and does not include analytics tools, advertising scripts, or ad services. When you open an external link, the third party may handle the request under its own policies.

GitHub Pages or another hosting provider may record general access information under its own policy; those records are not controlled or read by this site's code.

The recommendations page contains external links. When visiting a third-party site, refer to its privacy policy and terms.

## Policy updates

If the site adds or changes data, import/export, analytics, advertising, forms, or backend features, this notice and its date will be reviewed and updated.
