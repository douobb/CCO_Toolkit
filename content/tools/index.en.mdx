## Tools area

This area brings together the interactive tools. The tool itself appears near the top of each page, while its calculation logic and game data remain separate from the interface.

## Input locations

Tool inputs are divided into two groups based on how often they are adjusted:

| Input type | Purpose | Wide desktop layout | Mobile or narrow layout |
| --- | --- | --- | --- |
| Primary inputs | Values adjusted frequently and used directly in the current calculation | In the **Primary inputs** section of the main tool area | In the same **Primary inputs** section of the main tool area |
| Low-frequency inputs | Prices, buffs, and calculation settings that change less often | In the **Settings** tab of the right sidebar | Select the settings icon in top bar to open the bottom panel |
| Player & calculation settings | Manage player, equipment, and calculation data that multiple tools can reuse | At the bottom of the left sidebar, above the language selector | Click the player and gear icons in the top CCO Toolkit bar; this entry is separate from an individual tool's gear settings icon |

The layout changes according to the main content area's actual available width, so a narrow desktop window may also use the mobile settings entry point.

## Data storage

Tool inputs and settings are stored only in the current browser and are not sent to a server. Shared values that support synchronization use the browser's local storage for other tabs on the same site.
