Fields marked “Shared” sync with shared settings, and changes apply to other tools.

**Reset this tool** restores only that tool's trial inputs, mode, default buffs, or form and filter state; it does not change shared data or clear backpack inventory or loot-box records.

## Data storage

Tool inputs and settings are stored only in the current browser and are not sent to a server. Shared values that support synchronization use the browser's local storage for other tabs on the same site.
