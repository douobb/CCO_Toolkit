# CCO Toolkit

[English](README.en.md)

面向 CyberCode Online 玩家的非官方計算工具與遊戲教學網站，與遊戲開發者無隸屬或背書關係。

以 Next.js、React、TypeScript 與 Fumadocs MDX 建置，採靜態匯出。

- 遊戲：[CyberCode Online](https://cybercodeonline.com/)
- 遊戲資料來源：[CCO Found](https://docs.google.com/spreadsheets/d/1wJLuZhZg_Xs1ouyjh6chntY8p3lcgNTuRU3-9JwKxQ4)
